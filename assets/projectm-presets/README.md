# projectm-presets/

Bundled default projectM `.milk` presets for the visualizer
(`crates/external-bridges/visualizer-projectm-frame-bridge`), shipped with the
app so preset switching works out of the box. Only redistributable presets
belong here.

Populated in Phase 4 — see `docs/04-phase-roadmap.md`. Until then this
directory only carries `.gitkeep`.
