# Phase Directories

Stage-by-stage implementation guides. Each phase gets its own directory
named `phase-N-<slug>/` (slug = short kebab-case phase name from the
[roadmap](../product/04-phase-roadmap.md)).

## Convention

- One directory per phase: `docs/phases/phase-N-<slug>/`.
- Inside: the kickoff prompt, plus any phase-specific notes/checklists.
- Numbered docs keep their stable numeric prefixes; "doc N §M" references
  remain valid wherever a file lives.
- Current phase status is tracked in [`TODO.md`](../../TODO.md) at repo root —
  that file is always the live source of truth for what's active.
